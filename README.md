# 연주회 프로그램 편집기

연주회 프로그램 한 페이지를 브라우저에서 바로 고치고 PNG 로 저장하는 편집기다.

웹페이지: https://tael.github.io/concert-program/

## 사용법

- 글자를 클릭하면 바로 수정된다
- 사진 칸을 클릭하거나 사진을 끌어다 놓으면 교체된다
- 상단 "내 이름" 칸은 지휘자 이름을 바꾼다
- 수정 내용은 브라우저 localStorage 에 자동 저장된다
- "PNG 저장" 은 2526x1785 원본 크기로 저장한다
